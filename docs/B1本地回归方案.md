## 测试层次

1. 合成数据自动测试：隔离库生成文本、图片、文件引用、分组、收藏、敏感记录与设置；导出后恢复到独立目录，比较记录语义、对象哈希、分组和设置，不依赖真实历史。
2. 异常回归：错误密码、头部/块/清单篡改、截断、重复/重排、尾部垃圾、路径穿越、大小上限、空间不足、取消及中断；失败不得发布新库或更改当前定位。
3. 用户指定包回归：用户明确指定本地文件后，只读打开归档，在本任务新建的隔离目录恢复。密码通过本地输入传入，不放命令行、日志、报告或配置。只报告数量、比对结果和错误，不输出历史正文、文件路径清单或密钥。测试副本不连接剪贴板、不触发粘贴或自启动。
4. 跨账户/电脑：独立验证恢复端重新用其 DPAPI 保护主密钥，重启后能打开；本机同账户成功不能替代此项。没有环境时明确记为未测。

## 当前界面人工验收（待用户执行）

1. 打开设置→数据存储。选导出父目录，修改为不存在的归档文件名，点击“开始导出”；密码框只在弹窗中出现。取消或Esc关闭弹窗后重新打开，应为空白。两次密码不一致时不能开始。
2. 输入相同密码并确认导出。快照阶段提示暂停记录复制，随后显示进度；关闭再打开设置能继续管理任务。写入期可取消，发布期不能取消；任务结束前不要退出应用或关机。
3. 选择恢复归档及不存在的新目录，点击开始后在弹窗输入密码。解密验证成功自动出现替换确认；点“暂不替换”时原库继续使用，结果区可稍后发起替换。
4. 确认使用导入数据替换当前历史，点击“确认替换并重启”。重启后应显示导入的历史、分组、收藏及设置，数据目录指向恢复新库；原库完整保留，数据存储页“上次切换保留副本”应指向原库。不合并旧库之后新增记录。
5. 错误密码/损坏归档、已有目标、无法写入的配置或占用中的新库应报错且不切换当前库。若隔离环境未配置启动定位，允许导出/恢复但切换会被拒绝。
6. 归档运行中迁移按钮禁用，后端也拒绝迁移重启；替换验证/提交期间不能启动新归档。未保存其他设置时先保存或取消这些更改。

上述原生对话框、真实用户包、实际进程重启步骤未由自动化执行。当前自动化使用隔离数据库、Session重新初始化与Edge无头实际渲染；不代表跨账户或真实应用重启人工验收通过。
