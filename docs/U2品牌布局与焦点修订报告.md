## B-03：标题栏点击导致失焦自动隐藏

用户报告开启失焦隐藏后，点击标题栏也隐藏窗口。旧实现直接对 `Focused(false)` 隐藏。核对已安装 tao 的 Windows 实现，WM_KILLFOCUS 可引发该事件，不能仅凭它判断用户已切换到外部程序；本轮只读了现有诊断尾部，没有足够的对应焦点事件时间线，未在真实产品中重现。

修订为等待 120ms，随后在 UI 线程重新读取最新开关，并用系统前台 HWND、GA_ROOT 和 GA_ROOTOWNER 核对归属；主窗口自身、子窗口、所属窗口仍在前台时保留显示，确认前台离开后才隐藏，并继续发送 main-hidden 清除敏感原文。没有改动粘贴、钩子或修饰键路径。

新增两项 Rust 回归：开关/前台状态的隐藏策略；真实隐藏窗口的主窗口、子窗口、owned 窗口、外部窗口及空句柄归属。隐藏测试窗口不显示、不调用 SetFocus/SetForegroundWindow，不接管用户键鼠。这些验证证明判定逻辑与 HWND 归属，**不能替代实际标题栏点击、拖动、最大化与外部切换的原生复测**。
