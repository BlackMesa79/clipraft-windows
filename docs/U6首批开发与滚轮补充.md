## 本轮交付

1. 目录按钮：`item_detail.rs`复用单次后台metadata读取同时返回exists和is_directory；`itemDetail.ts`增加字段，`MainWindow.vue`按类型显示按钮、title与aria-label。普通文件仍显示“打开文件”，失效项仍禁用；无法读取类型时不猜测目录。路径读取失败不向前端暴露底层异常。
2. 鼠标滚轮：`hook/wheel.rs`接入WH_MOUSE_LL，与键盘钩子共用线程和既有Action消息。向上上一条、向下下一条，方向键和原V键照常使用；鼠标不必移到卡片上。只在快速选择会话活动、原修饰键仍按住、未取消且未录制时接管真实垂直滚轮。松开修饰键提交、Esc取消、ID会话与后端粘贴协议沿用。关闭、取消、未就绪时透传，横向与注入事件透传；不激活quick或更改鼠标穿透。
3. 高精度滚轮按120单位累计，整格可连续移动多条；新会话不继承旧余量。投递失败清除余量；若同一消息已有成功移动则吞掉该滚轮，避免同时滚动原应用。钩子只做固定大小状态和非阻塞投递，不访问存储或解密内容。两个钩子使用同一RAII注册，第二个安装失败会释放第一个，退出时均释放。
4. U6默认皮肤：Rust枚举与TS字面量`skin: clipraft`，缺字段默认回退，未知值沿用逐字段容错；复用保存事务、settings-changed和applyTheme三窗口入口。B1可迁移白名单包含skin；不新增数据库schema，不显示只有一个选项的选择器。设置初始草稿兼容旧字段，已有迟到快照和失败回滚规则保留。

## 人工验收步骤与后续确认

2026-11-17用户确认目录文案和滚轮选择没有问题，两项补充功能验收通过。下列细分边界未逐项声明，不推断为全部覆盖；U6专项与DPI/多屏仍待验收。继续开发见 [U6主题基础实现与验收](U6主题基础实现与验收.md)。

使用独立开发测试数据启动新构建，由用户决定时机；不覆盖正在运行的用户EXE或偏好。

1. 复制一个目录，在主窗选中，确认底部“打开目录”，点击应进入目录；选择普通文件应显示“打开文件”。检查刷新、失效、敏感项禁用与原有规则一致。
2. 保持原快速面板快捷键修饰键按下，滚轮上下移动，穿插方向键和V；确认选择、计数、首尾循环一致，松开后粘贴最后一项。不要要求鼠标位于卡片内。
3. Esc取消、松开修饰键、主窗录制快捷键、仅错误提示及未呼出面板时，滚轮应恢复原应用滚动；新会话不继承上次半格余量。验证触控板/高精度设备、连续滚动与单条/空历史。
4. 浅深色×列表/双列/紧凑核对默认外观、选择/焦点/滚动锚点；设置保存与取消/失败、未保存草稿、重启、密码备份恢复保持一致。quick与只读浮窗同步且不激活隐藏窗口。
5. 原生透明、输入法、焦点、125%/150%DPI和多屏仍需真实环境验收；离屏渲染不代替这些结论。
