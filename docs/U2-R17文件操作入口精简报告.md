# U2-R17 文件操作入口精简

2026-11-13。用户反馈R16测试未遇问题，本轮按最新偏好精简菜单与预览入口。主对话完成开发、审查与测试；未委派、未接管键鼠、未启动原生产品或外部应用、未修改manual数据、未提交。

## 当前规则

| 位置 | 单文件记录 | 多文件记录 |
|---|---|---|
| 右键菜单（普通/紧凑） | 用默认应用打开；在资源管理器中定位 | 仅一个“在资源管理器中定位”，不显示打开按钮及逐文件子菜单 |
| 普通模式预览详情 | 保留打开按钮；移除定位按钮 | 每个文件保留打开按钮；所有定位按钮移除 |
| 紧凑独立浮动预览 | 继续只读展示 | 继续只读展示 |

多文件的统一定位沿用后端reveal、索引0：打开首个文件所在目录并选中首个文件。无需在菜单枚举各文件，也不批量打开。即使记录路径不是同一个目录，也明确以首项作为本次定位目标，不依赖“所有路径必然同目录”的假设。

移除了ContextMenu中的文件子菜单状态、展开/返回分支和文件名渲染，保留原有分组子菜单键盘协议。文件类型/敏感标记/有效性限制、失败提示、普通粘贴、浮窗自适应高度及窗口防护均不改变。没有Rust、IPC、数据库或依赖变更。
