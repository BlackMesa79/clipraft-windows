## 目标与当前起点

快速面板选择覆盖全历史，打开时冻结顺序，新采集/重新复制不插队，首尾循环；前端只接收选中邻域的安全视图。保持默认选第二条、单条选第一条、Esc 取消、松修饰键按后端选中 ID 提交，以及现有掩码、粘贴代号、焦点恢复协议。

| 入口 | 当前实现 | U3 调整 |
|---|---|---|
| `runtime.rs::refresh` | 后台从 `Storage::list` 取首页到 `State.items` | 后台构建全历史 ID 索引，成功后原子替换；就绪与失败状态显式化 |
| `runtime/panel_controller.rs::open` | 从内存首页 `take(9)`，Panel 保存完整 ItemView 数组 | 获取不可变 ID 顺序快照，建立会话及选中 ID；不能同步查全表 |
| `runtime/panel_controller.rs` 的 `navigate/commit` | 按 Panel.items 下标移动并提交该项 ID | 纯会话状态机按全局序号移动；提交读取选中 ID，与邻域是否加载分离 |
| `runtime/panel_controller.rs::history_changed` | 只用首页内容替换旧快照，选中项消失则取消 | 对整个活动会话处理删除/过期/敏感变化，不以跌出首页视为删除 |
| `storage/mod.rs` | `list_page` 稳定排序 `pinned DESC,touched DESC,id ASC`；`preview_item` 按 ID 取安全视图；`existing_panel_ids` 最多 9 条 | 独立 ID 顺序查询、分批有效性核对与邻域安全视图查询，移除全历史场景的 9 条限制；不全库解密 blob |
| `panel.ts` / `QuickPanel.vue` | items/selected/visible/error 协议，列表直接渲染全部 items | 增加会话版本、总数/全局位置与局部选中位置；邻域缓存有界，明确加载/失败状态 |

`publish()`、`panel_state`、低级键盘钩子和控制线程 Open 路径不能取得 storage 锁或同步等待 SQL。沿用现有后台执行机制；不新增数据库 schema 或依赖，若实施发现确需变更应单独说明依据。

## 实施顺序

1. **纯会话模型及测试。** 定义不可变顺序、会话编号、选中 ID/位置、邻域请求版本；覆盖空/单条/两条/超过 200 条、双向循环、连续方向输入。当前选中项被删除或到期则取消，不自动把同下标另一条当作用户选择；其他项移除后保留选中 ID。
2. **后台 ID 索引与存储接口。** 只查询排序所需 ID/元信息；刷新成功后发布完整版本，失败不把残缺快照发布为新版本。首次索引未就绪明确反馈，不能阻塞钩子，也不能悄悄宣称仅首页就是全历史。约定何时可使用旧索引及提交前有效性复核。
3. **邻域异步取数。** 请求携带会话与版本；连续翻动、关闭重开或历史安全状态变更后，迟到响应丢弃。新增/重复制仅影响下次打开的顺序；敏感变化必须及时使缓存失效并更新打码视图。未加载位置不复用上一条内容，不向前端发送全历史正文或图片。
4. **接入 runtime 与前端。** 先保留现有列表外观，实现全局位置与局部邻域显示。Commit 始终按后端选中 ID 发起并由存储加载校验；失败明确反馈，不回退到旧 ID。滚轮几何、透明窗口和动画留在 U4。
5. **回归和原生清单。** 对上述竞态和安全行为进行集成测试，复跑 M1/U1/U2；新增 U3 专项及用户原生验收步骤，通过后再推进 U4。

## 必须验证的边界

| 场景 | 通过条件 |
|---|---|
| 201 条以上及首尾往返 | 可到末尾，两个方向循环，默认第二条规则不变 |
| 打开后新增/重新复制/置顶排序变化 | 当前会话不插队、不重排；下次打开使用新顺序 |
| 删除、到期、清空 | 深页也能发现；当前项失效取消，其他项变化保持选中 ID；不能粘贴别条 |
| 敏感状态变化 | 深页缓存及时更新/失效，后端打码，不请求敏感缩略图，不泄露旧正文 |
| 连续按键、慢取数、立即松键 | 选中状态与显示分离，提交 ID 正确，加载失败不复用旧内容 |
| 关闭重开、旧请求乱序返回 | 按会话及版本拒绝旧响应，不覆盖新选择 |
| 锁竞争及初始化失败 | 钩子、Open、publish、panel_state 不等待存储；有明确就绪/失败行为 |
| 原生协议回归 | 首次/连续呼出、Esc、不同松键顺序、焦点目标及混合 DPI 单独记录 |

B-01 保持暂缓；B-02 在触碰输入衔接前保留当前证据与基线，若复现单独处理，不猜测修复。U3 不扩展全局鼠标滚轮捕获、分组键位、Fluent 或背景图。可见条数 3～15（含旧偶数值）保留兼容，展示规则在 U4 落实。真实键鼠控制仍须事先明确授权；默认静态、后台、隔离数据和离屏验证，主对话独立完成。
