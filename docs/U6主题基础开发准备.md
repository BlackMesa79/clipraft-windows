## 交付目标与边界

U6交付当前外观的可扩展基础：整理已有语义颜色、角色尺寸、形状、阴影和动效令牌，统一组件状态，建立与明暗和布局独立的skin配置及跨窗口应用路径。默认皮肤须保留0.6.2已确认的外观与交互。

| 本阶段纳入 | 后续阶段或独立需求 |
| --- | --- |
| 默认皮肤令牌、组件状态、最小skin配置与兼容读取 | U7：Fluent完整控件、Mica/Acrylic/HostBackdrop材质与回退 |
| 三种主窗布局、quick和只读浮窗的外观同步 | U8：背景图片导入、加密资产、图层与回收 |
| 旧配置、保存失败、草稿、锚点与备份恢复兼容 | 语言切换、system明暗、主题包导入及任意CSS编辑器 |
| 减少动效和键盘焦点状态的基础约定 | OCR、编辑新建、云备份/同步、macOS |

仅有一个已实现皮肤时不显示无效的皮肤选择器，不创建尚不可用的Fluent或材质选项。默认布局、颜色和卡片几何不借此重新设计；若确需改变已确认视觉，先独立原型评审。
