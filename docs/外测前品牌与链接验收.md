## 本次改动

- 品牌继续使用 **片筏剪贴板 / ClipRaft**；最终图标为 C「柔和青玉」，接入主窗品牌图、托盘和多尺寸 ICO。
- 快贴 / PasteDash 的选定 B 图标及候选方案已保存到 [品牌归档](design/brand-archive/README.md)，此前箭头设计稿保留在 `docs/design/pastedash/`。
- 类型筛选选中项统一使用与左侧菜单相同的 `--select` 背景和 `--accent` 文字，选中后 hover 不再跳色，键盘焦点环保留。
- 非敏感链接记录提供“用默认浏览器打开”：普通/双列布局在详情区显示按钮，三种布局均可通过单选记录右键菜单打开。原有双击/Enter 粘贴行为保持。
- 打开操作只向后端提交记录 ID，后端读取完整存储内容，复用既有 HTTP/HTTPS 链接判定规则及 8KiB 上限；拒绝不存在、到期、敏感记录及不支持的协议。操作不会改写剪贴板。
- 普通文本记录即使带 HTML 格式，只要既有分类与链接规则认可，仍可作为链接打开；只有 HTML、没有纯文本载荷的富文本不提供该入口。

## 本地人工复验

构建产物位于 `.tools/pretest-preview-secondary-bin/ClipRaft.exe`。独立入口：

```powershell
./scripts/start-pretest-acceptance.ps1
```

使用独立的 `.test-data/pretest-acceptance/` 数据和配置；重复运行保留测试数据。不要与正式实例同时运行。脚本只供用户主动启动，自动回归不执行此脚本、不接管真实键鼠或剪贴板。

1. 查看主窗口、任务栏和托盘是否显示 C 图标，暂停/恢复的状态仍可辨认。
2. 深色模式下切换“全部/文本/图片/文件/链接”，核对选中背景与左侧菜单一致，hover 不跳色；再检查浅色与紧凑布局。
3. 用户主动复制一个 HTTP/HTTPS 链接，分别通过详情按钮和右键菜单打开，确认调用自己的默认浏览器且地址完整。
4. 普通文本与敏感记录不显示打开入口；取消敏感标记后可打开。选中记录与粘贴行为保持。

上述品牌及功能已获用户本机确认。本次已验收布局：粘贴按钮在左侧占主要宽度，右侧84px次要按钮显示“打开链接”或“打开文件”；文件入口仅对非敏感单文件提供，已失效或详情未就绪时禁用；多文件不新增底部打开，原逐项操作保留。单文件正文的重复打开按钮已移除。图片和链接预览不再重复显示大标题。此前已通过项目不要求重复验收。
