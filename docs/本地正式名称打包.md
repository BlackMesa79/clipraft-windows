## 命名规则

窗口中文名保持「片筏剪贴板」，英文产品名为「ClipRaft」。此前Cargo默认取早期包名，导致直接构建输出 `clipboard-m0.exe`；仅设置productName不会更改该进程文件名。

现在 `Cargo.toml` 显式声明 `[[bin]] name = "clipraft"`，并在 `tauri.conf.json` 设置 `mainBinaryName = "ClipRaft"`。标准打包命令：

```powershell
npm run tauri build -- --no-bundle --ci -- --locked
```

该命令通过项目环境脚本设置Rust工具链和2线程构建限制，自动构建前端并内嵌到Release，最终输出 `src-tauri/target/release/ClipRaft.exe`。已实测命令与最终文件名。原PowerShell包装器的高级参数绑定会截获CLI参数，本轮改为捕获并原样转发 `$args`，包含分隔符 `--`。

若直接执行Cargo，应先加载 `. ./scripts/env.ps1`；生成名为小写 `clipraft.exe`。只有Tauri build负责最终正式大小写；两种路径都不再把旧包名作为新的exe文件名。内部Rust包名 `clipboard-m0`、库名 `clipboard_m0` 和应用标识仍保留，避免无关迁移；构建日志可能继续出现包名，不是程序改名失败。
