# U4 背景 A/B 接入与验证记录

日期：2026-11-15。用户授权把 A、B 都接入产品以便比较；主对话独立开发、审查和测试，未委派、提交或推送。

## 使用与行为

设置 → 外观 → **快速面板背景**，提供：

- **B · 雾面托盘**：默认。浅/深主题采用各自的半透明圆角托盘、细边框及内高光，增强卡片与后方内容的区分。
- **A · 柔边暗幕**：局部渐隐暗底，尽量弱化外部容器边界。

点击保存后生效，保存选择后重启仍保留。背景设置与主窗口布局、主题选择独立；取消或保存失败保留原配置。不增加预览稿中的演示桌面、按钮或说明。

B 本轮实现的是半透明雾面外观，不对后方原生窗口或桌面做实时模糊；未引入 backdrop-filter 冒充原生跨窗口材质，也未提前实施 U6。原型采用网页模糊，产品通过较高的不透明度和渐变高光维持辨识度，实际外观由用户复测。

## 实现边界

- Rust `QuickBackground` 为强类型枚举，序列化为 `soft` / `frosted`。新增 `quick_background` 设置，默认 `frosted`；沿用现有 settings 表逐字段持久化和校验，不升级 schema、不引入依赖。
- 旧配置缺字段、无效枚举或损坏行按现有机制独立回退 B，加载不修写数据库。旧完整 IPC 设置缺少新字段时采用 serde 默认值。
- `SettingsView.vue` 在外观分类提供下拉框；`QuickPanel.vue` 通过现有 settings-changed 接收保存结果，使用同一舞台内的背景层。
- 背景仅在普通滚轮阶段存在，独立错误胶囊不携带背景。A/B 均不接收鼠标，背景边界不超出舞台；尺寸、工作区缩放、计数与卡片几何不改。
- 卡片仍不透明，中心项、140ms 动效、U3 安全摘要和 ID 选择、松修饰键提交、Esc 取消、非激活与鼠标穿透保持。未改钩子、粘贴或 Open/publish 数据路径。

## 用户复测

1. 打开设置 → 外观，确认默认 B。保存 A 后呼出滚轮，再保存 B 后呼出；比较复杂应用窗口、明亮文档和桌面壁纸上的辨识度。
2. 分别切换浅/深主题，确认背景、卡片及右上角计数可辨认；卡片不因位置变淡，间隔和 3D 效果保持。
3. 重启开发进程，确认上次选中的 A/B 保留。先修改后取消，不应改变已保存模式。
4. 测试连续选择、松键粘贴、Esc、边缘位置与混合 DPI；背景跟随舞台，不裁掉中心项，不抢焦点或鼠标。

本轮不接管真实键鼠/剪贴板，不修改 manual、真实偏好或用户当前窗口。不自动启动产品供验收；用户测试期间不再修改产品代码。下一步等待本轮原生效果反馈，U5 尚未开始。
