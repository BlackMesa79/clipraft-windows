# U7 Fluent 皮肤开发准备

2026-11-18。用户已确认第二轮 [Fluent 设计定稿](design/U7-Fluent设计评审稿.md) 和 [交互原型](design/u7-fluent.html)。实色皮肤已接入三窗口，自动检查和 WebView2 下拉验证见交接文档。原生材质留待实色验收后专项开发。当前工作区包含已验收且尚未提交的 U6 实现及日用调整。接续入口和基线见 [handoff](handoff.md)、[主题扩展与背景图评估](主题扩展与背景图评估.md)及[U6 实现与验收](U6主题基础实现与验收.md)。

## 视觉方案

按已确认的 Windows 11 Fluent 视觉方向实装以下组件的实色浅深外观和交互状态，沿用片筏剪贴板的信息结构和品牌。

| 区域 | 设计内容 |
| --- | --- |
| 主面板 | 区分导航、历史内容和预览操作层级，实现分组与当前记录的选中标识、搜索框、预览按钮，以及三布局的信息密度。 |
| 设置、菜单及对话框 | 实装分组设置卡片、下拉浮层、选中和焦点状态。覆盖确认、危险、禁用、错误、加载、短过渡与系统减少动效。 |
| 快速面板 | 沿用 3D 卡片、左上取消提示、右上计数和独立错误胶囊。接入 Fluent 表面、边框、阴影和排版，保留透明窗口、点击穿透和非激活行为。 |
| 只读浮窗 | 实装图文及敏感占位的表面、边框、阴影和字号，复核箭头、圆角、屏幕边缘避让及长内容滚动。 |

## 开发顺序

1. **实色 Fluent。** 以已定稿原型为视觉基线，复用 `src/styles/tokens.css` 的组件角色、`applyTheme` 和 Rust/TypeScript 的 `skin` 约定。保持 `clipraft` 为默认和存量回退值，明暗及布局独立，旧设置、B1 导入和旧归档走现有兼容路径。小范围组件变体复用现有事件及设置草稿。下拉框按键盘、焦点、滚动与浅深样式在目标 WebView2 中验证，动效遵循系统减少动效设置。
2. **三窗口集成。** 用同一份设置同步模式检查首次打开、迟到设置、保存和取消、窗口复用及启动恢复。核对滚动锚点、已选记录和分组身份色，保留 quick 的后端会话和 `quick-geometry.json` 共享几何。三窗口落地后开放 Fluent 选项，并完成实色效果和交互回归。
3. **原生材质专项。** 主窗单独验证 Mica，短暂浮层按需评估 Acrylic。quick 保留透明舞台和独立投影，后续材质探索可参考[原生合成归档](archive/u4-host-backdrop/README.md)。按窗口验证材质无法启用时的实色回退。U8 的自定义背景图沿用后续独立计划。

## 验收

- 自动检查覆盖两个皮肤、浅深色、三布局、三窗口设置传播、键盘焦点、菜单和弹窗状态，以及旧设置与旧密码归档。沿用现有 Rust、前端及状态/离屏脚本，保留当前片筏外观的计算样式对照。
- 实际渲染核对原生材质、窗口前后台、系统透明开关、高对比度、减少动效、混合 DPI 和多屏。记录 Mica 或浮层材质是否真实绘制，逐项复核纯色回退、拖动缩放、隐藏与重开、焦点和鼠标穿透。后台探测用于验证能力与生命周期，原生视觉结果单独记录。
- 快速面板验收同时覆盖空格、右键和 Esc 取消，松开修饰键后没有粘贴。用滚轮或方向键选中记录后正常松开修饰键仍会提交。主面板以目标应用与记录来源不同的场景复核「粘贴此条记录」。
