# U8 自定义背景开发准备

2026-11-22 启动，基线为 `v0.7.0`。背景图基底独立于皮肤，先覆盖素笺和 Fluent 的主窗口，包括常规单列、双列及紧凑布局。《孤星》继续在设计稿中迭代，客户端接入另行评审。

## 验收结论（2026-11-22）

- 用户实机复测素笺与 Fluent、浅色与深色，以及应用和移除自定义背景的来回切换，未再出现白色边线，确认 U8 自定义背景验收完成。
- 普通布局与紧凑布局分别保存图片和显示参数。普通布局的单列与双列共用背景，旧图片和参数归入普通布局。
- 最终自动验证通过 929 项 Rust 测试和 16 组状态及离屏回归，U2 共 169 项，含两套皮肤的壁纸边缘像素回归。下文的「待验收」描述保留为阶段过程记录。

## 首批范围

- 在设置「外观」提供本地 PNG、JPEG、WebP 的导入与移除。应用保留静态显示副本，允许覆盖、完整显示、五种对齐位置和遮罩强度调整。背景有独立应用操作，其他设置继续使用现有草稿。
- 后台限制源文件为 24 MiB、1600 万像素且单边不超过 8192 像素，生成长边最多 1920 像素的 JPEG，重编码移除源元数据。显示副本和外观参数作为单条资源保存在 SQLCipher 数据库中，随数据目录迁移和密码快照保留。替换以单次写入完成，移除删除当前资产记录。
- 主窗口有已加载的背景时采用图片基底，Fluent 系统背景透出在移除后恢复。高对比度使用系统配色。快速面板和浮动预览继续使用其现有外观。

## 验收

- 单元回归覆盖旧数据、损坏和过大的图片、源文件移除后读取、显示参数持久化、替换、移除及便携快照。
- 离屏覆盖背景导入、显示参数、失败回退、移除和两种皮肤。实机独立验收文件选择窗、Fluent 原生材质切换、高 DPI、文字对比度及拖动表现。

- 历史页使用同一张壁纸，内容底板、普通记录和详情使用各自的半透明表面。选中记录及搜索、操作控件沿用对应皮肤的配色。
- 用同一张合成壁纸复现了旧构建的设置页露图。新回归检查两套皮肤、浅深配色、单列、双列、紧凑布局和系统高对比度。离屏预览位于 `.tools/u2-ui/u8-wallpaper-*.jpg`。
- 前端格式、lint、构建、Rust 格式、clippy 和 929 项 Rust 测试均通过。16 组状态与离屏回归通过，其中 U2 共 167 项。日志位于 `.tools/u8-wallpaper-regression/`。

## 普通与紧凑布局独立背景

- 普通布局的单列与双列共用背景。紧凑布局可单独保存图片、显示方式、位置与遮罩。原有图片和参数直接进入普通布局。未设置图片的布局采用皮肤默认背景。
- 外观页上方并列展示横向与纵向窗口预览。选中预览后可独立导入、调整或移除该布局的图片。两个资源随数据目录和密码快照保留。
- 应用图片后隐藏主窗边缘及历史页结构分割线，保留控件和选中状态。原生外框隐藏沿用 Fluent 主窗口的 DWM 边框与客户区处理。
- 前端格式、lint、类型与构建、Rust 格式与 clippy 均通过。Rust 首次复跑遇到链接器无法打开测试可执行文件，待前一轮退出后串行重跑，929 项通过。16 组状态与离屏回归通过，U2 共 168 项。原生窗口外框仍待实机复核。

## 顶边与设置样式复修

- 启用自定义背景时关闭主窗的无装饰原生阴影。Tauri 的该阴影会附带一像素白边，之前仅调整 DWM 边框颜色和顶部客户区。当前布局恢复默认背景时恢复原生阴影。
- 外观页按「主题」「自定义背景」「布局」排列。Fluent 的背景表单共用主题卡片色，素笺沿用设置页底色。
- 隐藏 WebView2 主窗口探测通过。启用自定义背景后四边客户区缩进归零，恢复默认背景后原生阴影缩进恢复。该探测验证原生几何。
- 前端格式、lint、构建、Rust 格式、clippy、929 项常规 Rust 测试和 16 组状态与离屏回归通过。日志位于 `.tools/u8-top-edge-regression/` 和 `.tools/u8-top-edge-native.log`。

## 主窗边缘与材质分离

- 用户实机确认上一轮关掉阴影后，圆角和阴影消失，顶边仍有细线。旧实现曾在切回默认背景时恢复 DWM 默认描边并移除顶部客户区处理。上一轮的隐藏窗口尺寸测试只覆盖了缩进，无法确认可见白线的绘制来源。
- 主窗在创建时保留原生阴影，统一设置 Windows 圆角偏好和无描边，并让客户区覆盖顶部。主窗接管传统非客户区绘制，激活状态变化沿用系统处理并跳过旧边框重绘。皮肤与壁纸只切换背景，不再重置窗口边缘。最大化仍沿用 Tao 的工作区计算。[DWM 窗口属性](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute)
- 「自定义背景」与「主题」「布局」共用字号、字重和字宽。隐藏 WebView2 测试验证两套皮肤、添加和移除壁纸及改变窗口尺寸后，顶部缩进保持为零，其他原生边缘尺寸保持一致。桌面合成的可见圆角、阴影和顶边仍待实机确认。
- 隐藏窗口回读验证 DWM 圆角偏好切换前后均为 `DWMWCP_ROUND`，HostBackdrop 专项探测通过。前端构建、格式、lint、Rust 格式、Clippy 和 16 组状态及离屏回归通过。Rust 一次复跑在归档恢复测试中遇到 Windows `0x80070005`，未改归档代码，串行复跑 929 项通过。日志位于 `.tools/u8-frame-regression/`、`.tools/u8-frame-native-final.log` 和 `.tools/u8-frame-rust-retry.log`。

## 四边客户区与像素验证

- 用户实机反馈上一版顶边仍有白线，侧边与底边露出桌面。独立 Win32 像素探测复现了问题组合。保留非客户区缩进并拦截绘制会在窗口内容之外留下色带。
- 主窗改为四边完整客户区，撤销 `WM_NCPAINT`、`WM_NCACTIVATE` 及顶部专用子类处理。圆角偏好和无描边由 DWM 在主窗创建时设置。壁纸和皮肤切换不参与窗口边缘处理。另做的一像素底部延伸在桌面合成里产生亮边，最终采用零延伸。[微软自定义窗口框架参考](https://learn.microsoft.com/en-us/windows/win32/dwm/customframe)
- 独立 Win32 桌面探测的四边完整客户区保留了可见圆角和阴影。独立 WebView2 窗口采样核对了四边与内容中心的颜色一致。其桌面区域被前台窗口遮挡，改用仅捕获探测窗口的方式。WebView2 样本用于核对内容边缘，窗口外阴影由 Win32 合成样本核对。探测使用合成内容和独立临时配置。
- 预览与探测文件位于 `.tools/u8-edge-probe-full_client.jpg`、`.tools/u8-edge-webview-client.jpg` 和 `.tools/u8-edge-pixel-probe.py`。
- 929 项 Rust 测试、两个隐藏原生探测、16 组状态与离屏回归通过。U2 共 168 项通过。前端与 Rust 格式检查、lint、Clippy 和构建通过。最终检查日志位于 `.tools/u8-edge-final-rust.log` 和 `.tools/u8-edge-pixel-regression/`。

## 壁纸上下沿的底色细线

- 用户实机反馈，有图时上下边缘仍有细线，浅色尤其明显，无图时没有该问题。截图浅色顶沿的 RGB 为 `251,252,251`，等于 Fluent 的背景底色。Edge 渲染实际主窗时复现了同样的顶沿 RGB。
- 主窗的一像素边框设为透明后仍占宽度。原来的壁纸按内边距盒定位，在铺满模式下会露出边框区域里的主题底色。改为按边框盒定位，壁纸覆盖到外沿。该规则只应用于有图的历史页。[CSS 背景定位规范](https://www.w3.org/TR/css-backgrounds-3/#the-background-origin)
- 用实际样式在独立 WebView2 窗口中采样。改动前顶沿为 `251,252,251`，底沿为 `251,251,251`。改动后两个边缘与内容区每个颜色通道相差不超过 1。Edge 像素回归同时检查素笺、Fluent、浅深色和普通及紧凑布局。样本位于 `.tools/u8-wallpaper-native-before.png` 与 `.tools/u8-wallpaper-native-fixed.png`。
- 深色设置页的细线是另一处样式差异。已选壁纸时，设置页隐藏图片，但窗口外描边仍取 Fluent 的 `#43514d`。现在当前布局有图时统一隐藏主窗外描边，设置页内部轮廓沿用皮肤样式。Edge 渲染与独立 WebView2 窗口均复现了改动前的描边 RGB `67,81,77`。修正后外沿与设置背景均为 `32,41,39`。样本位于 `.tools/u8-settings-native-before.png` 与 `.tools/u8-settings-native-fixed.png`。
- 前端构建、格式、lint、Rust 格式、Clippy 和 929 项 Rust 测试通过。16 组状态与离屏回归通过，其中 U2 共 169 项。最终前端回归日志位于 `.tools/u8-wallpaper-edges-final/`。
