## 实现与安全边界

- `runtime/panel_controller/session.rs`：Controller 独占 Coordinator/Loader、单调会话编号和历史版本；后台 reader 取得 storage 锁并补文件状态，通过合并通知交回控制线程。Loader 不存回 State，避免引用环。
- `runtime/panel_controller.rs`：Open 只读取内存索引/设置，导航不等 SQL；Commit 消费 Coordinator 的选中 ID，即使视图尚未到达或读取失败也不会改用旧正文的 ID。关闭、主窗切换、设置打开和失败取消同步清理会话及邮箱。
- `runtime/history_gate.rs`：历史修改开始前递增全局版本、标记活动修改并清空共享面板正文；结束后再次递增并通知。`publish` 和 `panel_state` 在同一短内存门内核对版本，拒绝修改期间或旧版本的正文，覆盖数据库已变更但控制消息尚未处理的间隙。控制线程在修改期间先清空视图，最后一次修改结束后再核对整个冻结会话。
- 删除、历史/分组/敏感修改、采集保存/清理、设置保存和到期清理均接入安全门；门不跨越 SQL。并发修改计数确保某个修改提前结束不会恢复旧正文。发布和查询不获取 storage/采集锁；已有测试继续持有这两把锁验证真实发布与 IPC 状态读取。
- 历史变化后按全会话核对有效 ID，再取最新选中的邻域；新增/重复制/置顶重排留到下次打开，不把首页或邻域当成全部有效集合。删除当前项取消，其余删除保留选中 ID。
- `storage/panel.rs`：ID 索引、完整有效性核对、邻域读取排除逻辑上已到期但尚未物理删除的记录。粘贴 worker 使用 `load_for_paste`，在原存储加载边界检查删除/到期；不存在时明确报错，不回退其他 ID。保持原有加载、写回、松键等待、焦点和注入阶段协议。
- `panel.ts` / `QuickPanel.vue`：原子替换整份安全状态，按发布 serial 拒绝迟到事件及初始化快照；展示全局行号和计数、加载、查询失败。未加载时立即清空正文。`HistoryList.vue` 继续复用原样式，敏感项即使携带旧缩略图字段也不创建图片请求。
- 可见条数设置 3～15 用于邻域读取，包含旧偶数设置；当前仍为固定高度列表，15 条可能超出窗口可视区，选中项保持在局部中央。U4 再落实条数对应的滚轮几何，不将本轮当作滚轮设计验收。
