## 三个独立维度

| 维度 | 候选值 | 作用 |
|---|---|---|
| 主题 | 浅色青绿、深色蓝灰 | 控制背景、文字、强调色、边框与阴影，覆盖主窗口、设置和快速滚轮 |
| 常规布局 | 单列列表、双列卡片 | 控制历史组织方式；常规模式保留预览，主题变化不切换布局 |
| 紧凑模式 | 开 / 关 | 收成约 390px 窄窗，单列、无侧栏、无预览，保留搜索和轻量筛选 |

用户已确认默认：浅色青绿＋A 单列列表；初始紧凑关闭。正式实现时持久化外观偏好；主窗口布局不影响快速滚轮的五条选择结构。

v2 总体效果已获用户认可，模式规则继续沿用：从单列或双列进入紧凑后都统一呈现竖直列表；退出恢复此前的常规布局。紧凑期间修改常规布局选择，只修改退出后的恢复偏好，不把窄窗变成双列。这样不会产生“无预览双列”与用户竖直列表要求的冲突。

## 紧凑内容与行为

- 每条一行：类型图标或小缩略图、摘要/文件名、时间或重要状态。敏感标记、失效状态优先于普通来源信息。
- 不显示详情栏，不通过 hover 偷偷展开另一块预览。需要读长文、看大图或显式显示敏感原文时，先展开常规视图。
- 紧凑是可点击、可搜索的主窗口模式，和不抢焦点的快速滚轮是两个用途；不把它改成另一个快捷键浮层。
- 模式/主题切换保持选中记录与筛选。正式实现还需按记录 id 恢复滚动锚点、保留窗口位置，并分别记住常规与紧凑尺寸；原型只演示选中项和筛选保持。
- 多选、删除确认、右键菜单、长分组名、加载失败、敏感倒计时的最终呈现，下一轮精修补齐。紧凑没有详情不等于允许绕过敏感原文的显式显示流程。

## v2.1 紧凑精修（2026-11-12）

用户指出紧凑视图中分组与类型两排标签容易误导，同时要求增加行高，让缩略图更容易看清。已更新同一 `index-v2.html` 入口：

- 分组/收藏改成带“范围”标签的下拉选择，选项分为全部历史、收藏和“我的分组”；右侧显示当前筛选数量。这样不会把收藏误称为一个用户分组。
- 内容类型另起一行，明确标注“类型”，第一项由“全部”改为“全部类型”，避免与“全部历史”含义混淆。范围与类型之间有细分隔线，两个条件可以组合使用。
- 行高从 39px 增至 **54px**；缩略图从 25×25px 增至 **44×38px**，仍不展开预览面板。保持窗口高度时可见条数相应减少，列表正常滚动。
- 未来自定义行高/宽度纳入扩展清单；本轮只预留集中尺寸变量，不提供持久化自定义设置。正式实现需限定合理范围，缩略图保持原比例，并考虑高 DPI 与字体缩放。
- 局部预览：[浅色紧凑](v2-a-compact-detail.jpg)、[深色紧凑](v2-b-compact-detail.jpg)。两张均已目视确认标签区分、行高与缩略图呈现；截图为 390×554 JPEG。
- 六组合离屏检查再次通过，新增断言验证行高 54px、缩略图高 38px，以及“工作范围＋文件类型”得到 2 条、计数同步。原生产品仍未修改。

默认方向已定；本轮筛选区域与行高细化效果已获用户确认。产品实现从下一对话开始。


## v2.2 分组与收藏解耦

用户要求上方 select 只显示分组，收藏移出。原型调整为：

- 下拉标签“分组”，选项“全部分组 / 未分组 / 我的分组（工作、灵感）”，不再包含收藏。
- 类型栏右端增加独立星标按钮，与类型标签用短竖线分隔。空心为关闭，点亮为“仅看收藏”；提示文字与 aria-pressed 同步。
- 分组 × 类型 × 收藏为交集。例如“工作＋图片＋仅看收藏”；切换类型或分组不隐式关闭收藏，重复点击星标取消筛选。星标只筛选列表，不给当前条目添加收藏。
- 常规模式原有侧栏收藏入口与星标同步；紧凑/展开、主题切换保留筛选条件。未分组没有示例记录时显示明确空结果。
- 保持默认 A 单列＋浅色、紧凑行高 54px 和缩略图 44×38px。

同一交互稿入口已更新，六组合离屏检查通过；补充“分组下拉无收藏项”“工作＋文件＋收藏得到零条”“全部分组＋收藏两条”“再筛图片一条”断言。已目视检查新版浅色紧凑局部，分组与收藏入口清楚且无布局溢出。
