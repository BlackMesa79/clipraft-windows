## 查看方式

用浏览器打开本目录的 `index.html`，无需安装依赖或启动服务。顶部切换 A/B/C；可以搜索示例、按类型/分组筛选、选择记录、查看设置页，以及点击右侧按钮演示滚轮循环。粘贴等动作只显示演示提示，窗口控制符仅用于外观展示。

| 方向 | 主窗口与滚轮 | 设置示意 | 特点 |
|---|---|---|---|
| A 清晰工作台 | [预览](a-overview.jpg) | [设置](a-settings.jpg) | 浅色青绿，分组侧栏＋历史列表＋内容预览；优先推荐作为布局基础 |
| B 深色悬浮 | [预览](b-overview.jpg) | [设置](b-settings.jpg) | 蓝灰深色，窄图标栏＋双列卡片；适合偏图片和素材的使用习惯 |
| C 紧凑工具 | [预览](c-overview.jpg) | [设置](c-settings.jpg) | 暖白橄榄绿，顶部切组＋紧凑列表；一屏显示更多文本与文件 |

这些方向可以组合：例如 A 的三栏布局＋B 的深色配色，或 A 的布局＋C 的紧凑行高。深色配色不要求使用双列卡片。

## 设计建议

优先选择 A 的布局：与已有分组、搜索、收藏、敏感状态和预览能力匹配。主窗口承担管理和阅读，滚轮只承担快速辨认与选择，两者的信息密度应分别设计。

滚轮以中心项清晰为第一优先，透视与透明度只用于两侧层级，不让动画影响提交时机。正式卡片会单独确认实际像素尺寸、字体大小、不同桌面背景下的对比度。方向稿右侧的背景、说明文字和演示按钮属于评审画板，不是实际快速面板的一部分。

B 更有氛围，但卡片布局对长文本和路径的扫读效率较低，且分组图标需要提示。C 密度最高，但小字号和较短行高需要留意高 DPI 可读性。暂不增加装饰性图表、大块欢迎区域或产品宣传文案到实际主窗口。

## 当前覆盖与检查

- 同一组 8 条合成数据覆盖文本、合成图片、文件、链接、敏感内容与失效文件；包含内容预览、设置示意和 5 条滚轮。
- 使用独立 Edge 无头 profile、禁用 GPU 的离屏渲染，未抢焦点、未接管键鼠。三套稿均检查了无横向溢出、记录选择、图片预览、设置打开、滚轮首尾循环；680px 评审页无横向溢出。
- 预览为 1280×940 JPEG，每张不超过 300KB。已逐一目视检查三套主窗口；修正 B 的滚动条、图片卡片与滚轮缩略图后复查 B，并检查 C 设置页。A/C 的缩略图调整复用了相同结构，未另行重复读图。
- 检查脚本 `.tools/render-design.mjs`，结果 `.test-data/design-review/results.json`。仅证明方向稿实际渲染与演示交互，不证明原生 WebView2 透明、焦点、DPI 或真实粘贴。
- 菜单细节、完整设置分类、多选与批量确认、窄窗口实际应用布局将在方向确定后补齐；此稿不是最终开发规格。
