## 已确认的界面规则

| 项目 | 定稿 |
|---|---|
| 默认 | A 单列列表＋浅色青绿主题，紧凑模式关闭 |
| 主题 | 浅色青绿 / 深色蓝灰，独立于布局；控制颜色、边框、阴影，主窗口、设置和快速面板风格一致 |
| 常规布局 | A 单列列表 / B 双列卡片可切换，均保留内容预览 |
| 紧凑模式 | 独立开关；两种常规布局进入后都统一为窄幅竖直单列，隐藏侧栏和预览，不以 hover 弹出另一块预览 |
| 恢复 | 退出紧凑恢复之前的常规布局；主题、布局切换保留选中 id 与筛选；正式实现保持滚动锚点与合理窗口位置 |
| 紧凑尺寸基准 | 约 390px 窗宽、54px 条目高度、44×38px 缩略图；图片保持原比例，适配 DPI，不拉伸或硬裁切原图 |
| 紧凑信息 | 类型图标/缩略图、单行摘要或文件名、时间或重要状态；敏感/失效优先于来源信息 |
| 紧凑分组 | 独立标注“分组”的 select，仅包含全部分组、未分组、具体用户分组；不包含收藏 |
| 紧凑类型 | 另起一行标注“类型”：全部类型 / 文本 / 图片 / 文件 / 链接 |
| 收藏筛选 | 类型栏最右端星标，用短竖线与类型隔开；空心为关、点亮为仅看收藏，提供 tooltip 和无障碍状态；不是给选中记录加收藏 |
| 筛选组合 | 分组 × 类型 × 收藏取交集，切换其中一项不偷偷清空另外两项；计数和空结果同步 |
| 外观偏好 | 正式实现持久化主题、常规布局与紧凑开关，旧配置使用兼容默认值 |
| 未来扩展 | 用户自定义行高/宽度以后实现，本阶段集中定义尺寸变量；不提前加入未设计好的配置编辑器 |

## 快速滚轮

沿用已确认要求：透明无边框、无窗口阴影，只有卡片；默认 5 条、选中居中，上下透视、缩放、透明度递减，动画约 120～160ms；图片有缩略图，文字单行，错误为小胶囊。全历史可选并首尾循环，打开固定 id 顺序，仅取邻域安全视图。

快速面板继续不抢焦点、忽略鼠标，不受主窗口单列/双列/紧凑模式影响。保留现有快捷键和松键提交规则。主窗口紧凑模式不是快速面板。评审页桌面背景、演示切换控件和说明文字不属于产品快速面板。

## 新对话开发顺序

1. 先读 `docs/handoff.md`、本文、`docs/待修问题.md`、`docs/界面与滚轮开发计划.md`。
2. 优先复现日常使用 B-01 / B-02，主对话修复、Tester 补测；避免先改造输入路径后再查原问题。若缺具体环境无法复现，明确记录缺口，可推进不涉及输入路径的组件和主题工作，不能猜测修复或误标完成。
3. 按 U1～U5 推进组件基础、统一界面与外观偏好、全历史选择、3D 滚轮和整体回归。设计方向已确认，不再重新要求用户选 A/B/C。
4. 当前原型没有覆盖的多选、删除确认、错误、长分组、敏感原文生命周期等状态，沿用 M1 行为并按定稿风格实现，不减少已有能力；有实质设计冲突再澄清。
5. 主对话开发与复核；测试只通过 codeg-mcp 委派 Tester（assistant_id=3），不替换为原生子代理。不接管真实键鼠；原生操作依约先明确授权。

本轮仅归档设计与交接。产品实现仍是 M1 基线 `0fabee4`，两个新增 bug 未复现/未修复，既有未测环境继续保留。
