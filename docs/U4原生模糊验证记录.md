## 用户测试入口

重启开发进程，在 **设置 → 外观 → 快速面板背景** 中选择并保存：

1. **A · 柔边暗幕**：此次已修复窗口边缘裁切。先在浅色窗口或有明显横线的背景上观察四边，暗幕应自然消失，不再出现截图中的灰色平边。
2. **原生背景模糊（验证）**：本轮新增的 Windows Desktop Acrylic 路径，下次呼出时应用。观察后方文字是否真正模糊、卡片是否清晰、浅/深主题下的材质及边缘是否正常。
3. 随后切回 A/B，确认原生材质消失；测试 Esc、松键提交、连续开关、错误胶囊及工作区边缘。原生项报不可用时选择 A/B 继续使用。

已有选择与默认值不擅自改写：默认仍为 B，已保存的 A 保持 A。新验证项要求支持系统 backdrop 的 Windows 11（Build 22621 或更新）；若设置了原生项，保存后下次呼出生效。

原生验证采用整体圆角系统材质，**不承诺呈现 A 的柔边渐隐，也不提供可调高斯半径**。非激活时的模糊/染色/实色回退与系统设置有关，实际是否符合预期须本轮用户实测；属性接受不等于视觉通过。

## A 修复与像素验证

当前 `ellipse at center` 默认尺寸会让四边中点仍处在渐变内部，窗口边界将其裁成灰边。已改为显式 `ellipse 50% 50% at center`，让暗幕在四边之前进入全透明区，保留中心暗度和原卡片几何。

离屏测试克隆真实背景样式到白底，采集 PNG 并逐像素检查：四边中点 RGB 均为白底 255，中心仍小于 150。没有通过隐藏整层背景规避问题。另以深色卡片叠在浅色代码窗口上实际渲染并目视核对；预览 `.tools/u4-native-final/previews/background-soft-dark.jpg` 与 `soft-edge-probe.png`。

## 原生实现与清理

新增 `quick_material.rs`，使用现有 windows 依赖的 DWM 功能特性，不增加第三方依赖，Cargo.lock 不变。

- 新增强类型 `QuickBackground::Native` / `native` 持久值，旧 A/B 与独立字段回退机制保持。
- 在主线程的 quick 显示路径设置 `DWMWA_SYSTEMBACKDROP_TYPE=DWMSBT_TRANSIENTWINDOW`，并设置主题/圆角偏好；直接处理 HRESULT，再读回 backdrop 属性。未采用 Tauri 外层只返回排队成功的结果作为唯一依据。
- 显示失败会隐藏并尝试清理材质，通过既有错误胶囊反馈，提示切回 A/B；不静默伪装成功。
- 关闭、Esc、提交、主窗口切换、控制器异常、提示到期以及显示错误胶囊时清理 quick 原生材质。先隐藏再清理；取消材质成功后，装饰属性恢复失败记入诊断，不阻止返回 A/B。
- A/B 正常路径只检查本窗口是否有活动材质，不要求系统支持 DWM backdrop。原生项只作用 quick，不改变主窗口、预览窗口或系统偏好。
- 没有向 CSS 添加伪原生模糊；验证项的前端背景透明，系统材质不能通过离屏浏览器证明。原有窗口焦点禁用、NOACTIVATE、鼠标穿透、U3 ID 选择和粘贴流程保持。
