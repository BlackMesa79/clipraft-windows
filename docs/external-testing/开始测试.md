# 片筏剪贴板 / ClipRaft：开始测试

这是首批邀请测试候选版 `0.1.0-alpha.1`，请从项目负责人提供的压缩包解压到独立文件夹。不要直接在压缩包里运行，也不要与另一份 ClipRaft 同时运行。

## 第一次启动

1. 使用 Windows x64 标准账户；本批优先验证 Windows 11。Windows 10 的具体版本请记录在反馈中。
2. 系统需要 Microsoft Edge WebView2 Runtime。若启动提示缺失，请从微软官方渠道安装对应运行时，再重试；不要因为浏览器能打开网页就断定运行时可用。
3. 双击 `ClipRaft.exe`。主窗口初始隐藏，点击系统托盘图标或按 **Alt+V** 打开；快捷键冲突时可从托盘进入设置调整。
4. 先复制一段没有隐私的测试文本，再试搜索、粘贴。快速面板默认 **Ctrl+Shift+V**，按住快捷键、用方向键选择后松开。
5. 关闭主窗口不等于退出；完整退出使用托盘菜单“退出”。测试第一轮先不要开启开机自启动。

程序未做数字签名。若系统或安全软件拦截，请保留提示文字、核对负责人提供的SHA256并反馈；无需关闭安全软件或提升管理员权限。不要反复启动多个实例。

## 数据在哪里

程序默认将历史保存在 `%APPDATA%\ClipboardM0`，启动定位配置在 `%APPDATA%\ClipRaft`。这些是沿用的内部目录名，不代表名称没有改好；也可在设置中查看/迁移实际数据目录。删除exe或ZIP不会删除历史。

内容在本地加密保存，不上传到云端。默认开启敏感识别，但请用无隐私的合成文本测试，不把真实密码、token、私钥或工作机密当样本。点击“打开链接”会由默认浏览器访问相应网站。

原始数据库与密钥绑定Windows账户，不要直接把数据文件夹复制给别人或跨账户替换。需要迁移时使用设置中的密码导出/恢复，并妥善保存导出密码；不要把密码和导出包一起发送。

## 重点看看这些

- 左侧为宽的“粘贴到原窗口”，右侧较窄的“打开链接/打开文件”；打开文件只在单文件记录显示。
- 多文件不提供底部批量打开；可逐项打开或从右键定位。
- 图片与链接不再重复显示大标题，深浅主题的类型选中色应与侧栏协调。
- 原有复制/粘贴、中文输入法、窗口切换和快捷键松开行为应保持稳定。

完整检查见 `测试清单.md`，问题按 `反馈模板.md` 填写。每次反馈写明包编号和 `BUILD.json` 中的源码提交号。

## 升级与退出测试

升级前先密码导出备份，退出旧程序，把新包解压到另一个目录再启动。不要混用不同包里的文件或删除旧数据目录；遇到不能启动或历史异常，先停止使用并反馈，避免用旧版覆盖新数据。

不再测试时，从设置中关闭已启用的自启动，再从托盘退出。数据需要清理时，请先确认实际目录并自行备份，删除程序文件本身不会清理数据。
