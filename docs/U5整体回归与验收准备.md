## 可复用检查入口

先从仓库根目录加载 `. ./scripts/env.ps1`；Rust使用 `--manifest-path src-tauri/Cargo.toml`，测试 `-- --test-threads=2`，沿用脚本并发限制。

- `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check-m1.ps1`：fmt、全目标clippy、Rust、类型/Vite、M1 T1～T8离屏串行回归。
- `npm run format:check` 与 `npm run lint -- --max-warnings=0`。
- 构建后依次 `node scripts/check-u1-ui.mjs`、`check-u2-ui.mjs`、`check-u3-ui.mjs`、`check-u4-ui.mjs`（后三项同样使用 `node scripts/…`）。
- 状态/隐私：`node scripts/check-sensitive-privacy-ui.mjs`、`node scripts/check-main-preview-state.mjs`、`node scripts/check-hotkey-recording-state.mjs`。
- 独立设计稿 `check-u4-background-design.mjs` 不是产品验收入口；原生参考目录不参与编译，不运行它来证明当前产品通过。

ignored大图/性能项目先按用户负载和需要决定是否另测；默认不启动重型GPU任务。所有真实渲染证据均说明路径和局限，不能把只加载或隐藏属性探测称为视觉通过。
