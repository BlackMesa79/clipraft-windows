## 实现结果

| 需求 | 当前实现 |
|---|---|
| U2-R01 | main 禁用系统标题栏；顶部提供拖动区及最小化、最大化/还原、关闭按钮。窗口操作权限仅赋予 main，关闭沿用 CloseRequested 隐藏到托盘与 main-hidden。按钮不带拖动属性，品牌区域通过父 header 接收拖动。 |
| U2-R02 | 移除收藏视图、筛选、菜单、Ctrl+D、徽标、前端筛选字段及 set_favorite IPC 注册。数据库 favorite 列、旧数据和存储内部兼容方法保留；容量/天数清理 SQL 继续排除 favorite=1，不转置顶、不转分组、不改变排序，不升级 schema v4。显式到期和主动删除保留原语义。 |
| U2-R03 | 分组标签、下拉和类型按钮统一 12px / 18px，下拉取消原生外观并绘制箭头，避免原生 select 忽略行高。 |
| U2-R04 | 移出分组在实际分组之后，前置分隔线、浅深色红底、继承文字颜色的 SVG 解除关联图标及说明 tooltip；仍发 move_to_group(null)，沿用多选与键盘导航。 |
| U2-R05 | 双列统一 248px，预览 94px，摘要两行，状态区固定分配空间，敏感/失效状态排序优先；缺省占位，图片 contain。锚点采用实际边界定位，切换短行时限制过大的旧负偏移，保证锚点仍可见。 |
| U2-R06 | 通用、外观、历史记录、隐私、快捷键五分类共享同一草稿。内容独立滚动，保存统一提交，取消恢复最近保存值并返回列表；底栏独立占位并容纳错误、状态、清理确认。600px 以下分类改为顶部选择器。 |

旧版收藏的保留保护由既有 `cleanup_protected_records_neither_deleted_nor_counted` 等存储测试继续覆盖；本轮没有写迁移或解除原保护。批量主动删除确认使用“受清理保护”措辞，计数覆盖置顶、分组和旧收藏的并集。
