## 当前基线

- ClipRaft 是 Windows 剪贴板管理器，使用 Tauri 2、Rust、Vue 3、TypeScript 和 Vite。
- 当前源码与正式发布版本均为 `0.9.0`，BP1 已通过用户实机验收。见 [v0.9.0 发布说明](https://github.com/BlackMesa79/clipraft-windows/releases/tag/v0.9.0)。
- U8 自定义背景已验收，功能提交 `92a919c` 已随 `v0.8.0` 推送至 `main`。下载入口和更新日志已同步。
- U7 Fluent 主题已通过用户测试并发布。默认主题显示名为「素笺」，持久化值仍为 `clipraft`，旧设置保持兼容。
- Fluent 覆盖主面板、紧凑布局、设置页和相关窗口，支持浅深色、背景透出强度与主题化控件。共享开关组件 `src/SettingToggle.vue` 保留默认主题复选框和 Fluent 开关两种呈现。
- 本地构建与测试缓存维护已完成。清理了 11 个旧 Rust 构建目录和 2,083 份历史 Edge 离屏配置，D 盘可用空间净增 148.27 GiB。共享构建目录与 Edge 配置清理已验证，933 项 Rust 测试和 18 组状态、离屏及渲染检查通过。

## 开发约束

- 先核对 `git status` 并保留用户现有工作。开发、审查和测试由主对话完成，不委派。
- 真实键鼠控制需针对具体操作先获得明确授权；不修改 `.test-data/manual`、用户偏好、当前场景或日常运行实例。
- Rust 命令先加载 `. ./scripts/env.ps1`，使用 `--manifest-path src-tauri/Cargo.toml`；测试线程数设为 2。
- 完成阶段工作后按 `AGENTS.md` 运行 fmt、clippy、Rust 测试、前端格式/lint/build 和相应状态/离屏回归。不要对整个项目批量格式化。
- 临时工作副本的 Rust 缓存、归档和 Edge 配置清理按[构建缓存与离屏测试](../AGENTS.md#构建缓存与离屏测试)执行。
- 提交和推送需用户明确授权。`docs/` 下阶段准备、设计、评估和验收等文档默认保留本地；提交文档时只纳入 `handoff` 这类持续交接文档，除非用户明确指定其他文档。文档与回复使用简体中文。

## 已知功能边界

- 发布形式为 ZIP 解压运行，`bundle.active` 为 `false`，未接入 updater。
- 用户于 2026-11-25 确认 K2 全部项目验收通过。快速面板纯文本粘贴随后按用户要求移除，不纳入交付范围。Fluent 提示样式收口也已完成。
- K2 主面板导航支持 ↑/↓ 首尾停止、Home/End 和 PageUp/PageDown。End 会加载剩余分页，筛选变化会取消旧跳转，快速面板循环保持不变。
- K2 键盘与鼠标钩子具备健康检查及掉钩恢复。用户验收通过。
- K2 隐私设置支持关键词和正则忽略规则，限制为最多 50 条、每条 200 字符。规则只过滤之后复制的文本，不回溯历史。用户验收通过。
- 普通文件记录保存路径，不包含原文件；源文件移动或删除后，相关文件操作可能失效。
- 动图目前可能只显示静态首帧。QQ 等应用的文件型记录可保留文件原始格式供粘贴，但不代表已实现动画预览。
- HTML 图文预览会安全提取并重编码内容；RTF 可采集和写回，尚未实现 RTF 预览解析。
- U8 背景图覆盖素笺和 Fluent 主窗口。普通布局和紧凑布局各自保存图片与参数，调整显示需使用「应用背景调整」。动图预览、富文本预览增强、编辑/新建记录和自动安装更新尚待开发。
