## 模型约定

- `Session::open` 接收不可变 `Arc<[String]>` 顺序及本次唯一会话编号。空历史返回 `None`；单条选第一条，其他情况选第二条，复用已有选择计算。
- 方向使用 `Direction` 枚举；全历史双向循环。新建记录、重复制、置顶或后台新索引不会改变活动顺序。
- `reconcile` 只剔除失效记录，保留其余记录顺序和选中 ID；当前 ID 被删除/到期时取消，清空同样取消。调用方必须传入整个会话的完整有效性集合，失败或部分结果不能用作删除依据。
- 选择与邻域加载分离，`commit` 消费选中 ID 并结束会话。未取数、取数未完成或失败都不构成回退到旧 ID 的理由；关闭后重复提交不产生 ID。
- 邻域只复制最多 15 个 ID，不携带正文、缩略图或解密对象；全局位置、总数和局部选中位置独立提供，位置从零开始。保留 3～15 的偶数条数兼容；小历史不重复 ID。
- 每次方向输入、邻域请求、安全失效、有效性核对及取消都会推进修订号。响应只在活动会话且编号/修订号一致时有效，覆盖关闭重开、同位置重试、翻走后返回等乱序情形。

`invalidate` 只提供纯模型的版本失效能力；后续 runtime 还须清空旧安全视图、重新取打码数据并拒绝敏感缩略图。模型测试不能证明这些尚未接入的安全行为已经在产品中实现。会话编号唯一性由调用方保证，接入时不能复用。
