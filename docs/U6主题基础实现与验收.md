## U6.4组件状态矩阵

| 组件 | normal / hover / pressed | selected / focus-visible | disabled / error / 敏感 |
| --- | --- | --- | --- |

| 普通操作、菜单与预览按钮 | 控件角色背景/文字/边框；已有hover走control-hover-bg；没有自定义pressed的控件保持现状 | 2px内绘焦点；危险菜单项保留danger环和错误背景 | 普通按钮0.45、原表单/弹窗0.5、原底栏0.4分角色保留，不将已有差异机械抹平 |
| 主粘贴按钮 | primary-bg/primary-text；hover/pressed亮度1.08/0.92 | 沿用可见焦点 | disabled不进入hover/pressed |
| 设置、表单与录制 | 控件最低高度、字体、边角及hover边框统一来源；不增加额外动画 | 页面选中态使用selected角色；输入焦点与Tab语义保留 | 原生fieldset/disabled、aria-invalid及录制冲突错误角色保留 |
| 分组 | groupColors按稳定ID产生身份色，主题仅选明度 | 身份色不被通用selected角色抹平 | 删除分组和菜单错误保留危险语义 |
| 备份与清理弹窗 | 共享弹窗形状、阴影、遮罩和按钮角色 | 原有焦点约束、原生dialog和键盘行为不变 | 禁用确认、密码/迁移错误保留；不改变业务判断 |
| quick | 透明底和不透明卡片；同一后端选择ID | 卡片选择边框和计数不由动画决定 | 胶囊错误、打码、只读无焦点、减少动效路径不变 |
| 只读浮窗/图文 | 共享字体、边角、阴影；原生透明箭头保持 | 没有可操作控件，不新增伪焦点 | 错误、敏感清空、坏图提示及内容代次不变 |
