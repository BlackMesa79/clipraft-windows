# M0 人工验收清单

> 适用版本：clipboard-m0 0.1.0（Tauri 2 + Rust + Vue 3，M0 技术验证原型）
> 整理依据：README「人工验收步骤」1–12、`docs/需求整理与选型评估.md` 第一/三/四节
> 用途：以下项目**必须由人在真实桌面环境操作**，自动化测试无法替代（不接管键鼠、不向真实应用发送按键）。
> 执行方式：逐项勾选，填写「结果」与「备注」。发现问题按「附三」的模板记录。

## B. 快速面板选择语义（README 2）

- [ ] 在记事本依次复制 A、B、C，主窗口历史顺序为 C、B、A（最近的在最上）。
- [ ] 激活另一个文本输入位置，**按住 Ctrl+Shift 后按 V**：面板出现，默认选中**第 2 条**（B），第 1 条是当前剪贴板内容。
- [ ] 面板显示时按 `V` 或 `↓` 选到 A；按 `↑` 回到 B；列表两端应循环。
- [ ] **（D-3 修复后新增）按住 `V` 不放约 1 秒**：选择只前进**一格**，不随自动重复连续翻页；松手后再按一次才再前进一格。连续「按下—松开」5 次应恰好前进 5 格，目标程序里不出现任何 `v`。
- [ ] 呼出后**先松 Shift 或先松 Ctrl** 都试一次：**只粘贴一次**，且目标处不会出现多余字符甚至 `v`。
- [ ] 再次复制与某条历史完全相同的内容：该条置顶且**条数不增加**。
- [ ] 只有一条历史时呼出面板：默认选中该条（第 1 条），方向键仍在同一条上循环。
- [ ] 清空历史（隔离目录内新起一次）后按 Ctrl+Shift+V：不应弹出面板，也不应向目标程序键入任何字符。

## C. 取消与成对按键（README 3）

- [ ] 呼出面板后按 `Esc`：面板消失且**目标程序没有任何粘贴**（目标里不应出现 Esc 的效果，例如对话框未被关闭到不该关的程度）。

- [ ] 不同松键顺序各试 3 种：松 Shift → 松 Ctrl、松 Ctrl → 松 Shift、同时松。
- [ ] 呼出后**先松 Shift 再按 V**（应视为普通输入，不重新打开面板、不粘贴）。

## D. 修饰键释放等待与输入恢复（README 4，重点）

> 目标：确认 `SendInput` 之后不会出现「看起来打不了字」的状态（docs 第一节根因 3）。

- [ ] 复制约 30MB 大图，快速面板粘贴后立即再打开面板选择另一条粘贴：不报错，最终粘贴的是第二次选择的内容；大图粘贴的等待时间明显缩短。在 QQ 和 codeg 草稿输入框分别复测，不发送消息；对照 `phase=load/write/wait/prepare/inject/touch` 和 `paste_superseded`。若第一次 Ctrl+V 已发送，则其目标端粘贴无法撤销，应另测第一次仍在 load/write/wait 阶段时的换代取消。
- [ ] 主窗口 Alt+V 选择大图粘贴后，立即再次 Alt+V 打开并选择另一条：旧任务静默退出，第二条正常粘贴；与快速面板交替呼出也不显示旧任务的超时提示。
- [ ] 先用 Alt+V 呼出并关闭主窗口若干次，再用快速面板连续粘贴 10 次，不应出现“请松开修饰键后重试”。启用诊断时保留 `toggle stage=before_show/after_show` 和 `paste stage=before_wait` 相邻日志，对照 8 个修饰键的 async/physical 状态。
- [ ] 在隔离数据下保持 Ctrl 或 Shift 超过 1 秒触发超时：错误提示按文字内容紧凑显示，无空白列表，约 2 秒隐藏且不抢焦点；提示期间重新呼出快速面板，列表尺寸恢复且不会被旧提示期限关闭。
- [ ] 快速面板粘贴后立刻输入普通字母，能正常输入（大写/小写与 Shift 状态一致）。
- [ ] 依次验证：`Ctrl+A` 全选、`Shift+方向键` 选中、`Alt` 打开菜单栏、`Win` 打开开始菜单。
- [ ] 提交后保持 Ctrl 或 Shift **未松开**：从大数据写回完成、`before_wait` 开始计算，1 秒内不应提前粘贴；释放剩余键后只粘贴一次。超过 1 秒应取消并显示“请松开修饰键后重试”，之后释放不能延迟补粘贴。
- [ ] 连续操作至少 **50 次**（快速面板 + Shift+Enter 交替），过程中随时输入文字验证可输入。
- [ ] 在**中文输入法组合输入状态**（拼音候选框打开）中重复上述操作，确认：
      - 候选框不消失、不被打断；
      - 粘贴结果符合预期；
      - 面板期间按键不进入输入法。
- [ ] 失败时记录：哪个修饰键卡住、卡住的组合键、能否通过再按一次该键恢复。

## E. 焦点、输入法与目标应用（README 5，重点）

对每个目标应用分别执行（记事本 / 浏览器输入框 / VS Code 编辑器 / 微信草稿框 / 管理员权限终端）：

- [ ] 面板出现时**焦点仍留在目标应用**：面板消失后直接打字，字符进入目标而不是面板。
- [ ] 面板出现时目标应用的**光标位置、选区、输入法状态保持不变**（面板不抢焦点、不触发 NOACTIVATE 失效）。
- [ ] 目标应用没有系统插入光标（如某些自绘控件）时，面板出现在**鼠标位置附近**，且不超出屏幕工作区。
- [ ] 面板显示期间把目标窗口切到另一个窗口（Alt+Tab 或点击任务栏）：**不得向新窗口误粘贴**。
- [ ] 面板显示期间关闭目标窗口后松开修饰键：应报错或取消，不应卡键。
- [ ] 管理员终端（以管理员身份运行的 PowerShell/cmd）：普通权限原型应提示「不能向其发送按键」，**不产生卡键**，剪贴板内容保持可用。

## J. 权限与异常（README 10）

- [ ] 向管理员权限窗口粘贴：普通权限原型应报错且不发生卡键。
- [ ] 粘贴前关闭目标窗口：错误可见，随后能继续复制与输入。
- [ ] 用合成内容产生一次外部复制变化后，由受控测试程序占用剪贴板约 1 秒：应在释放后采集成功，无占用错误；保持超过重试窗口时仅提示一次“剪贴板被其他程序长时间占用，本次复制未记录”。释放后原序列不反复补采，新复制仍能记录。
- [ ] 目标应用拒绝粘贴（例如只读控件）：剪贴板仍为选中记录，应用不崩溃。

**D-1 修复后必须人工确认的错误提示行为**（自动测试只覆盖计时逻辑，不覆盖窗口是否抢焦点）：

- [ ] 制造一次粘贴失败（例如复制文件记录后删除源文件，再按 Ctrl+Shift+V 粘贴）：快速面板位置**短暂显示「操作失败」和原因**，约 **2 秒**后自动消失。
- [ ] 提示显示期间**焦点仍在原应用**：不按任何键直接打字，字符进入原应用；面板不显示插入光标、不闪烁激活；任务栏不出现新按钮。
- [ ] 提示显示期间继续正常打字、复制、切换窗口，提示不遮挡也不打断输入。
- [ ] 提示尚未消失时**再次按 Ctrl+Shift+V**：面板应立即切回正常的历史列表（错误提示消失），并能正常选择与粘贴；旧提示的 2 秒期限**不得**把新面板关掉（关闭时机应从这次重新呼出后重新计时）。
- [ ] 提示消失后立刻按 Ctrl+Shift+V：面板能正常打开，不残留错误文字，也不出现「空面板」闪烁。
- [ ] **两次错误连续发生**（例如连续两次粘贴失效文件）：提示文字更新为最近一次的原因，并从最后一次错误起重新计满约 2 秒，而不是从第一次起算。
- [ ] 主窗口在前台时发生后台采集错误（用测试程序占住剪贴板 1 秒后再复制）：确认提示出现在**鼠标/光标附近**，并在约 2 秒后消失；主窗口自身的错误文字也应同步消失。
- [ ] 提示显示期间用 Alt+Tab 切到另一个应用：提示不跟随激活、不向新窗口粘贴任何内容；提示消失后新窗口能正常输入。

## 附二、已知限制（出现时不算缺陷，不要记成 bug）

- 无搜索、分组、收藏、历史清理、开机自启、应用忽略名单、敏感内容识别（M1 范围）。
- 主界面只取最近 200 条；快速面板最多 9 条且为打开瞬间的快照，新采集不改变当前选择。
- 快捷键为源码常量（`src-tauri/src/hook.rs` 的 `TRIGGER_VK`/`REQUIRE_CTRL`/`REQUIRE_SHIFT`），无设置界面，快速面板尚未开放 Alt/Win 组合配置；主窗口 Alt+V 已有即时掩码和 300ms 菜单保护。
- 文件记录只保存路径与复制/剪切语义，不保存文件快照；源文件失效时报错，列表暂不标注失效。
- 不抓取 HTML 远程图片；文件路径、HEIC、SVG 不生成预览；Word 专有格式、CF_BITMAP、OLE 不在范围。
- 普通权限进程遇到管理员目标只报错，不提升权限（UIPI）。
- 剪贴板写回与目标消费之间无事务保证：写回成功但按键失败时剪贴板仍为选中记录。
- 无生产级钩子健康监测与掉钩自动恢复；16 ms 显示延迟、多屏 DPI、远程桌面、休眠、输入法与修饰键竞态正是本清单要测的部分。
