## 审查发现与覆盖缺口

没有足够证据确认需主对话修复的产品缺陷，因此没有新增“待修”忽略测试。以下是覆盖边界，不能写成已验证通过的系统行为：

1. **自启失败与回滚缺少注入点。** runtime.rs 的 `autostart_changed = !state.smoke && ...` 会使现有 smoke fixture 跳过所有真实注册表操作；生产路径直接调用 autostart::set。静态可见自启写入失败时尝试恢复热键，落库失败时尝试恢复自启与热键，但本轮未运行这两种自启失败路径。建议主对话后续引入可替换的自启操作接口，再用假实现覆盖写入失败、恢复失败及错误信息；不应通过修改用户 Run 项制造失败。
2. **暂停完整线程链路未端到端验证。** 静态审查：worker 在 CAPTURE_GATE 内检查 PAUSED 并采集/保存；TogglePause 在同一门锁内确认当前 LAST_SEQUENCE、切换 PAUSED、清空 capture_context；启动设置在 worker/broker 工作前初始化 PAUSED。新增测试分别覆盖暂停入队入口和恢复后的序列去重，没有宣称它们等价于“控制线程+worker+真实剪贴板”的竞态验证。
3. **托盘设置原生显示未验证。** 静态可见菜单发送 OpenSettings，控制线程取消快速面板、显示主窗口并发送 open-settings；未就绪时由 settings_requested 在 frontend_ready 补发。离屏脚本验证的是事件到 Vue 设置页这一段，不代表实际窗口取消最小化、前台切换或首次加载补发的端到端结果。
4. **文件状态的时效和未知结果。** 过期后先返回旧状态并异步更新，符合当前实现；队列由独立单线程消费，慢网络路径可能延迟后续检查。测试用可控通道验证满队列恢复，用注入 exists 返回值覆盖权限/未知，不访问真实远端路径、不人为改变 ACL。实际删除/重建文件后 30 秒刷新及网络路径延迟可留给人工验收。
