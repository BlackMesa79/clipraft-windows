# U4 透明 3D 滚轮开发准备

日期：2026-11-15。前置：U3、S1、K1 已获用户验收，K1提交 `654340d`；B-10 HTML混合图文预览及敏感切换已获用户实测确认，本轮按授权提交。状态：恢复U4开发准备，未实现U4产品代码。

## 1. 本阶段范围

快速面板采用透明、无边框、无原生窗口阴影，仅绘制卡片；默认5条，选中项固定居中，上下通过透视、缩放、透明度和 rotateX 形成垂直滚轮，过渡120～160ms。单行文字、文件名、图片缩略图及小胶囊错误；不再保留旧的整块实色列表窗口外观。

保持 U3 冻结全历史ID顺序、后台索引、有界异步邻域、安全版本门；选中以后台ID为准，不能等视觉动画播放结束才提交。默认第二条/单条第一条、上下与现有触发键、松开修饰键提交和Esc取消全部保持。

不接入全局鼠标滚轮，不让快速面板抢焦点或接收鼠标；不改K1主面板筛选、数据迁移、密码方案或B1。B-09按用户明确要求仅记录，等再次出现后定位；B-01暂缓、B-02未独立定位，均不借U4猜测修复。

## 3. 实施拆分

### U4.1 几何与展示模型

先实现纯展示映射和对应测试：邻域选中下标转槽位距离；稳定key使用会话及记录ID；空/单条/少于一屏/首尾循环/删除或到期/加载失败明确化。选中项始终中心，邻域不足处留空，不重复同一记录填满。

可见条数3～15，默认5。偶数旧值必须在实施前定稿明确策略：保留持久值及兼容读取，不未经迁移拒绝；若采用展示奇数归一化，需要前后端一致并给用户可解释反馈，不能后台取4而前端假装5。此处是待实施设计项，不声称已实现或用户已经选定。

窗口几何以一套模型给出舞台宽高、中心行高、相邻位移和最大旋转范围；固定尺寸指同一配置的会话中选项变化不抖动，不等同所有条数永远530。窗口受工作区限制时要同步展示缩放/裁切策略，不能只让原生截短而盖住中心选中项。

### U4.2 滚轮组件与动效

组件仅接收后端安全视图，位置及选中来自PanelState。先生成无动画正确终态，再增加120～160ms过渡；连续输入直接趋向最新状态，不排队播放历史步骤。关闭重开、换会话和大跨度跳转取消旧动效，不呈现上一条旧内容为可提交项。

选中卡片正文单行截断，图片/文件缩略图保持比例；敏感记录只使用已打码信息，不请求原文或敏感缩略图，保留到期/无计时标记。加载和失败用稳定几何与小胶囊反馈，动画不改变后端选择。

支持 prefers-reduced-motion，无动效时选择和状态语义一致。共享现有颜色和选中/焦点令牌，不提前实现U6皮肤架构。

### U4.3 原生透明与尺寸/定位

CSS html/body/app和原生WebView窗口同时透明；仅CSS变透明不能算原生透明通过。quick无原生阴影，卡片内部阴影的几何空间要预留，工作区边缘不被切断。

沿用WS_EX_NOACTIVATE、鼠标穿透及现有show_quick目标校验。尺寸更新不能激活/显示隐藏窗口；notice延迟resize不得缩小刚打开的滚轮。核对初始窗口尺寸、前端就绪前状态、DPI转换和跨屏位置。

### U4.4 回归与用户验收

代码审查和自动回归后，再让用户原生验收透明、黑底/残影、焦点、输入法、连续粘贴、混合DPI和工作区边缘。缺环境照实记录，不以离屏截图代替原生透明证明。

## 4. 检查清单与边界

- 纯状态：可见条数3/5/7/15、偶数兼容、历史0/1/2/不足一屏/超过200条、首尾双向循环、记录ID和槽位key不重复。
- 异步与安全：旧serial/session/邻域响应丢弃、快速连按、加载中松键、敏感/过期/删除失效取消、无缓存旧原文复用。
- 离屏真实渲染：浅深主题、卡片透视与文字/缩略图、减少动效、无横向溢出、中心项位置稳定、错误胶囊、连续输入不积压动效；每个视觉目标按需压缩截图，不批量返回原图。
- 原生：透明窗口必须在实际WebView2路径测；无激活、无桌面剪贴板修改的隐藏启动只能证明启动/协议，不能声称视觉通过。
- 每阶段沿用fmt、全目标clippy、Rust测试(2线程)、Prettier、ESLint零警告、类型/Vite和handoff状态/离屏回归；使用scripts/env.ps1和隔离数据，不修改manual/用户偏好，不接管真实键鼠。

完成后更新handoff和实施记录，U4用户验收后进入U5整体回归；然后B1密码导入导出及迁移备份/清理，再首批外部测试、U6～U8。主对话独立开发、审查、测试，不委派。
