# U2 独立浮动预览修订报告

日期：2026-11-13。用户否决记录右端缩略图方案，确认恢复左侧缩略图，并为紧凑模式增加选中记录的独立浮动预览。主对话独立开发与测试，未委派、未提交。

## 当前行为

- 常规单列恢复在记录左侧显示类型图标或缩略图。普通类型图标统一 36×36，缩略图增大到 68×48；敏感记录显示类型/锁图标。双列继续等高卡片与顶部图片预览。
- 紧凑列表同样恢复左侧缩略图：普通类型图标 32×32，图片缩略图 52×38；仍保持 54px 行高、独立置顶图钉。右上刷新与标题栏紧凑切换继续使用上轮 28px 图标按钮。
- 紧凑模式选中记录后，新 `preview` 原生窗口只读展示图片、文本或文件详情。图片优先使用大预览并保持 contain，小图片可放大到内容区宽度；文本及文件列表可滚动，失效状态可见。敏感内容使用后端打码，无显示原文或粘贴入口。
- 浮窗默认 360×420 逻辑像素，优先在主窗口右侧，右侧不够放到左侧；两侧都不足时可缩窄到最少 180px，再不足则隐藏，避免覆盖主窗口。保留当前内容，移动主窗到有空间的位置后可重新显示。使用当前显示器物理工作区、DPI 和负坐标计算位置，跟随主窗移动/缩放。
- 浮窗为 main 的 owned 窗口，`focused(false)`、`focusable(false)`、不进任务栏，不调用 set_focus。主窗实际失去前台、隐藏、最小化、打开设置、退出紧凑或记录变化时清除/更新；WebView 的单独 blur 不直接关闭浮窗，沿用原生前台归属复核以免标题栏拖动误关。

## 实现与数据边界

新增 `src-tauri/src/compact_preview.rs` 管理原生位置、快照和请求代号，`src/FloatingPreview.vue` 为独立页面入口。只有 main 可更新浮窗，只有 preview 可读取快照；core 默认读取/事件权限增加 preview，不增加主窗口操作权限。

浮窗只提交记录 id，由后端在同一存储锁内按 id 读取安全 ItemView 与 display_detail(false)。新增 `Storage::preview_item` 不依赖 quick 的第一页缓存，超过 200 条的旧记录也可预览；复用既有后端脱敏与 thumb 协议校验，不接受客户端传入的原文或图片路径。

请求代号在新选择/隐藏时失效；最后发布与清空由同一锁串行化，迟到加载不能显示旧记录。浮窗先订阅事件再读初始快照，事件到来后不会被迟到初始快照覆盖，主题也使用相应的版本保护。main-hidden/history-changed 原生监听负责兜底清理。schema v4、数据目录、输入钩子及粘贴路径不变，无新依赖。
